# 🏥 Hospital Management System (C++)

A simple **console-based Hospital Management System** built using **C++** and **file handling**.

---

## 🚀 Features
- Add patient records
- View all patients
- Search patient by ID
- Data persistence using file handling
- Simple menu-driven interface

---

## 🛠 Technologies Used
- C++
- File Handling
- Object-Oriented Programming (OOP)
